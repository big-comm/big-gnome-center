# Community Menu

GNOME Shell 50 and 51 applications menu used by the Big Gnome Center.

The extension is a GPL-2.0-or-later derivative of Zorin Menu 5.3.5. It
keeps the application-list, application-grid, and Mint-style layouts while
using its own UUID, settings schema, name, and neutral artwork. Only the stock GNOME
panel and Community Panel are supported.

Layout mapping:

- `APPS_ONLY`: Classic
- `APP_GRID`: Desk-UX
- `MINT`: Hybrid

Hybrid is the default when enabled on BigGnome, Minimal, or G-Unity.
Legacy `ALL` and `SYSTEM_ONLY` values migrate to Hybrid.

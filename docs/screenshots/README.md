# README media

Captured from Big Gnome Center on GNOME 51, October 1, 2026.
The interface and GIF captions are in English. Frosted Glass is enabled.

- `big-gnome-center-demo.gif`: interface tour, light and dark themes.
- `layouts-light.webp`: six layouts and saved customizations.
- `themes-light.webp`: GNOME accent colors.
- `effects-dark.webp`: Frosted Glass surface controls.
- `extensions-dark.webp`: featured extensions.

Media uses real VM captures. The GIF shows navigation and theme changes;
it does not apply layouts or install extensions. Desktop chrome is cropped
out. Captions are added with FFmpeg; no application UI is composited.
